Force Templates - Sorting Explanation

.PK3 Files:

- The order for Force Templates depend on the .PK3 name (PK3s with "A" end up at bottom whereas "Z" end up at top)

.FCF Order:

- The Original Order of when each .fcf file was added to each .PK3 determines the loading order inside of that specific file

Custom Templates:
- Custom ones are in the EternalJK/Forcecfg folder and will always be at the very top of the list
